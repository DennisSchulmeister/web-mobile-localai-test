# AI Coding Agents

* Before using `poetry` or any other Python command, `cd` into `server/`.
* When working on the frontend web app, `cd` into `app/`.
* When working on the Capacitor Android app, `cd` into `android/`.
* Don't change existing Django migrations. Use `./manage.py makemigrations`, instead.
* When updating documentation, also update the Table of Contents (links) at the top.
* When writing utility scripts: Log each step of the script on the console.
